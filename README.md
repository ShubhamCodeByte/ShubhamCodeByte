# Hi there, I'm Shubham Singh 👋

**Automotive Cybersecurity Engineer | AOSP & Linux Specialist**

I am an Automotive Cybersecurity Engineer focused on hardening In-Vehicle Infotainment (IVI) systems and securing the Android Open Source Project (AOSP) ecosystem. I specialize in bridging the gap between low-level hardware security and framework-level application architecture.

### 🛡️ What I Do
* **System Hardening:** Managing end-to-end AOSP build creation, SELinux policies, and dm-verity for strict filesystem integrity.
* **Security Architecture:** Validating Secure Boot and Android Verified Boot (AVB) to ensure hardware-backed chains of trust.
* **Threat Analysis:** Conducting deep-packet network analysis (Wireshark), Weak Cipher Analysis, and DoS mitigation.
* **Core Development:** Building secure Inter-Process Communication (IPC) pipelines using HIDL/AIDL, JNI, and C/C++.
